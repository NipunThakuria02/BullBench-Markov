Scope: five Yahoo auto-adjusted equities and separately reported manual NSE Indices NIFTY 50. This is an exploratory research track, not official-only validation, G0 approval, or the official EXPERIMENT_PROTOCOL.md freeze. Owner authorized final evaluation and newer training on 5 November 2026. No prospective observations are currently available beyond the imported 16 October 2026 endpoint.

## Frozen before test generation
- Data: immutable imported snapshot versions with source/canonical hashes in each run manifest. Real observations only. Vendor revisions cannot be reconstructed point in time; no claim of a point-in-time vendor database.
- Origins: observed source sessions, including unverified duration/special-session types. No filled rows, no mixing official raw equity closes with vendor-adjusted closes, no pooled equity/index currency errors. Official calendar amendments, source-availability timing and official adjustment verification remain unresolved, recorded in CALENDAR_EVIDENCE.md and CORPORATE_ACTIONS.md. Do not call the observed calendar verified.
- Return: log adjusted close ratio for equities; log index-point close ratio for NIFTY. Target: absolute next observed-session log return exceeding the asset's fixed 80th percentile from target sessions through 31 March 2023. The threshold is retained across later fits; it is not tuned on test to produce events.
- Features: origin return, absolute return, 5/10/20/60 observed-session rolling standard deviations. Complete windows only; long source gaps (>5 calendar days) block the run. Standard scaler fitted on training pairs only.
- Fit targets through 31 December 2024. Validation origins from 15 April 2025 with targets through 30 September 2025. Historical test origins from 16 January 2026 with targets through 16 October 2026. Assert at least 60 observed-session embargo origins between training/validation and validation/test. Neither embargo outcomes nor validation outcomes fit parameters; sequential filtering/ARIMA state updates may consume past observed outcomes causally.
- HMM: own NumPy diagonal Gaussian implementation on scaled return dimension only. State counts 2/3/4, seeds 42/43/44, max EM iterations 300, tolerance 1e-5, variance floor 1e-4. Only converged candidates eligible; minimum validation Brier wins with deterministic grid-order ties. Forward filtering only for predictions; no smoothing/Viterbi predictors. No post-test state/seed/grid changes.
- Comparators: training prevalence, previous event persistence, add-one observable binary Markov, Gaussian EWMA (lambda=.94), GARCH(1,1) Student-t (training-only fit, convergence required), logistic max_iter1000, random forest150/depth6/minleaf15/seed42, XGBoost150/depth3/rate.03/seed42. Supervised training uses the shared six features. Raw probabilities retained; no fitted calibrator is claimed. Decision cutoff chosen from .05:.05:.95 on validation macro-F1, tie first; one-class validation uses .5. Log all failures and evaluate all surviving models on common dates.
- Secondary: previous close, Ridge/RF/XGBoost/ARIMA, plus matched Ridge/RF/XGBoost with causal HMM probabilities. Same training/evaluation dates. ARIMA updates state on every intervening observed outcome after prediction without refitting parameters. Reconstruct closes with origin close * exp(predicted log return), never future previous-close factors. Block inconsistent price bases.
- Report: Brier/log loss/PR-AUC/balanced accuracy/macro-F1, events, base rate and skill vs frozen training prevalence. One-class class-dependent metrics remain null. Five-equity mean HMM Brier skill is descriptive, NIFTY separate. State the actual test's events and negative findings without retuning.
- Uncertainty: circular paired blocks10/20/40, 4,000 draws, seed42; pointwise and within-asset Bonferroni intervals, conditional on fitted predictions. No cross-asset correction, no refitting/bootstrap selection claim.
- Historical test is NOT untouched: this period was inspected for original price forecasts. No prospective or confirmatory claim. Save immutable predictions/config/arrays, source hashes/code hashes/library versions, protocol SHA and pre-test Git tag. Existing development runs remain unchanged.
- Separate newest-data HMM may be refit using fixed validation-selected state count/seed through 16 October 2026 for state exploration. It receives no out-of-sample score; historical test scores remain attached to the earlier model. New-session inference stays blocked until an explicit verified target-session calendar exists. Never invent November observations or a forecast target.
